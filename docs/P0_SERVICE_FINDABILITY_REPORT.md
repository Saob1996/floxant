# P0-Service-Findability

P0-Ziele sind über Header oder Leistungsmenü, Standort-Hubs, kontextuelle Servicekarten und interne Related-Links erreichbar. Dazu gehören die Düsseldorfer Reinigungsseiten, Regensburger Kernleistungen, Angebotsprüfung, Diskret-Service und Klaviertransport.

Sitemap und Navigation verweisen auf kanonische Ziele; Legacy-Pfade leiten weiter.

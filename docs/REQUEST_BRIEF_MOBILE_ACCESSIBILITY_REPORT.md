# Mobile- und Accessibility-Prüfung des Anfragebriefs

Der Anfragebrief und das Drei-Schritt-Formular verwenden semantische Überschriften, Fieldsets, Labels, Fehlerverknüpfungen und sichtbare Fokuszustände. Interaktive Ziele sind mobil ausreichend groß; lange Zusammenfassungen und Dateinamen dürfen umbrechen.

Der Fortschritt wird als „Schritt von drei“ beschrieben. Fehler fokussieren das erste betroffene Feld oder die Fehlersumme, und der Erfolg wird über einen Statusbereich angekündigt.

Die abschließende Browserprüfung kontrolliert zusätzlich horizontales Überlaufen und die tatsächlich hydrierte Formularansicht.

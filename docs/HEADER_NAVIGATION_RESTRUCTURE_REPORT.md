# Header-Navigation – Bericht

Der Header hält die erste Ebene kompakt, bündelt Leistungen im Mega-Menü und zeigt Angebotsprüfung und Kontakt als klare Aktionen. Mobile Schnelllinks verwenden dieselben kanonischen Ziele.

Die Navigation löst keine API-Aufrufe aus und trägt keine versteckten Stadt- oder Serviceannahmen in globale Kontaktlinks.

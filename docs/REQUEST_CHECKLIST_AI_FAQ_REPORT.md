# Checklisten, AI Answers und FAQ

Anfrage-Checklisten beantworten vor dem Formular, welche Angaben für Reinigung, Umzug, Transport, Entrümpelung und Sonderfälle hilfreich sind. AI-Answer-Blöcke liefern kurze, deterministische Antworten mit einem passenden nächsten Schritt.

FAQ-Inhalte ergänzen die Checklisten um Kostenfaktoren, Ablauf, Zugang, Fotos, Fristen und Leistungsabgrenzung. Sichtbare Fragen und strukturierte FAQ-Daten werden aus kontrollierten Datenquellen erzeugt; es werden keine unbelegten Sofort- oder Preisversprechen ausgegeben.

Die Regression `npm run ai:answer-regression` prüft alle Einträge sowie zentrale Intent-Fragen.

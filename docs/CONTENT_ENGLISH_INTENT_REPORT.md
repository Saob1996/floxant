# English Intent Report

Stand: 29. August 2026

English content is limited to useful service and request paths for international customers. The supported intent is practical: choose a service, state the location, describe scope and access, add timing and photos or an existing quote, and continue to the same contact flow.

The English routes do not claim separate branches, guaranteed English availability, fixed prices, rankings or legal advice. Düsseldorf cleaning intents and Regensburg moving/cleaning intents are separated by service and location. English pages use their own titles, descriptions, H1 and visible copy rather than translated keyword shells.

Checks: `npm run english:intent-health`, `npm run content:inventory`, hreflang/canonical validation in `npm run check:seo`, and production browser checks after deployment.

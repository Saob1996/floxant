# Content-Safety-Cleanup

Stand: 29. August 2026

## Verbotene positive Aussagen

Keine erfundenen Preise, Rabatte, Bewertungen, Referenzen, Zertifikate, Niederlassungen, Verfügbarkeiten, 24-Stunden-Zusagen, Versicherungszusagen, Ertrags-, Abnahme-, Kautions- oder Rankinggarantien.

## Eingebaute Grenzen

- Preisfragen nennen Faktoren und fehlende Angaben, aber keine erfundene Zahl.
- Dringende Anfragen werden auf manuelle Verfügbarkeitsprüfung gesetzt.
- Unbestätigte Orte werden nicht als Servicegebiet ausgegeben.
- Asbest, Chemikalien, Kontamination, Tatort, Schimmel, Desinfektion, Fassade, Lüftung und weitere qualifizierte Sonderfälle werden nicht als Standardleistung zugesagt.
- Nachlass- und Seniorenthemen grenzen Rechts-, Bewertungs-, Pflege- und medizinische Beratung ausdrücklich aus.
- Rückfahrten erscheinen öffentlich nur, wenn eine reale Tour als veröffentlicht markiert ist.

## Prüfungen

`npm run qa:content-safety`, `npm run copy:customer-language`, `npm run ai:answer-regression`, `npm run content-authority:health` und das HTML-basierte Inventar prüfen diese Grenzen automatisiert. Zweifelsfälle bleiben für persönliche Prüfung offen.

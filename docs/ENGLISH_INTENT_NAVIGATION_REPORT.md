# English Intent Navigation

Englische Einstiege liegen unter `/en` und verlinken zum englischen Kontaktweg. Alias-Begriffe werden auf kanonische Services normalisiert. Deutsche Seiten dürfen zusätzlich einen klar markierten englischen Anfrage-Link anbieten.

Globale deutsche Navigation wird nicht mit massenhaften Sprachduplikaten erweitert.

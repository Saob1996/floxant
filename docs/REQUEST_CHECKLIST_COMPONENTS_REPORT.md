# Request-Checklist-Komponenten

Die Komponenten `RequestChecklistBlock`, `PhotoGuidanceBlock`, `MissingInfoHelper`, `ObjectBriefPreview`, `CopyRequestSummaryButton`, `RelatedSignatureSuggestion` und `BetterRequestNotice` trennen Daten, Darstellung und Aktion.

Gemeinsame Datenquellen vermeiden widersprüchliche Checklisten. Kopieren bleibt eine lokale Browseraktion; Komponenten außerhalb des Formulars rufen keinen Lead-Endpunkt auf. Leistungsseiten können kompakte Varianten mit kontextuellem Kontakt-Link einsetzen.

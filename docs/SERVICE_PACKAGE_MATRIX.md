# Service-Package-Matrix

`lib/service-packages.ts` enthält Pakete für Reinigung, Umzug, Entrümpelung, Angebotsprüfung und Signature Services. P0-Pakete benennen benötigte Angaben, typische Aufwandfaktoren, Kontaktparameter und passende Zusatzservices.

Die Matrix unterstützt Auswahl und Rückfragen; sie ist keine automatische Preis- oder Verfügbarkeitszusage.

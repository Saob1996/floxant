# Diskret-Service – Routenarchitektur

`/diskret-service` ist das kanonische Ziel für sensible allgemeine Anfragen. `/diskreter-service` leitet dauerhaft dorthin. Der Kontaktweg übernimmt `diskret-service` als explizite Auswahl und sendet erst beim Formular-Submit.

Private Client und konkrete Leistungsseiten bleiben getrennte Intents und verlinken auf den Diskret-Service, wenn eine zurückhaltende Erstkommunikation wichtiger ist als eine spezielle Leistung.
